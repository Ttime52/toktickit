## Reflection

Overall: โดยรวม AI สามารถทำงานได้ดีถ้ามี prompt ที่ครอบคลุมและชัดเจน แต่อาจมีข้อผิดพลาดอยู่บ้าง การที่เราสั่งให้ AI ตรวจตัวมันเองอีกครั้ง หรือ run test ว่ามีข้อผิดพลาดอะไรตาม criteria ที่เรากำหนดไว้ และให้มันคิดว่าจะเป็นผลเสียในอนาคตหรือเปล่าก็จะทำให้ AI ทำงานได้มีประสิทธิภาพมากยิ่งขึ้น

Prompt 1 : ดูตอนแรกอาจนึกว่าไม่มีข้อผิดพลาด แต่พอลองให้ AI ตรวจตัวเองซ้ำอีกรอบโดยให้ดูความเชื่อมโยงของแต่ละไฟล์ที่มันเขียนด้วย พบว่ามีข้อผิดพลาด เช่น เลขอ้างอืง test ไม่ตรง, API ไม่ตรง หรือขาดบาง requirement จึงให้มันทำการแก้ไขและรีเช็คด้วยตัวเองซ้ำถึงออกมาค่อนข้างสมบูรณ์
